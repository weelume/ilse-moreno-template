| 区域 | 触发与表现 | 实现与验收 |
| --- | --- | --- |
| 首屏肖像／标题 | 页面进入，肖像位移及轻微旋转；选框标题错峰进入 | 独立 motion 轨迹；桌面、平板、手机布局分别检查 |
| 作品画布 | 进入约 35% 时从 82% 缩放到 100%，约 1.2 秒；作品按 0.09 秒错峰出现 | 实际检查了初始透明／位移与结束状态 |
| 拖拽 | 指针移动超过 5px 后平移，释放按末段速度滑行；画布边界限制可见区域 | 拖拽与释放实际触发；纯坐标逻辑有边界和中心缩放测试 |
| 缩放 | 50–200%，围绕视口中心缩放；按钮和键盘加减可用 | 已触发 100%→125%；纯逻辑检查缩放往返无漂移 |
| 项目聚焦 | 首次选择放大项目并显示侧栏，其他项目降低透明度；再次选择进入案例 | 聚焦、返回与案例导航实际验证；过渡约 0.6 秒 |
| 缩略地图 | 同步展示项目与可见区域 | 与视口位移和缩放联动 |
| 评价图钉 | 桌面浮层；手机模态弹层；Escape／关闭按钮关闭 | 桌面、手机实际打开关闭 |
| 画布／列表 | 保留六项目与完整案例导航，切换显示方式 | 双向切换实际验证 |
| 手机堆叠卡片 | 水平拖动并旋转，超过 50px 切换，否则归位；触控、方向键及功能按钮 | 切换与层级修复已验证；保留纵向页面滚动 |
| 图片／卡片 | 图片悬停放大 1.03；选框标签变紫；服务卡片轻微抬升 | 保留独立 hover 与按压状态 |
| 关于页示意 | 通话状态循环、双通道进度、编辑光标闪烁、周报错峰强调 | 使用组件内独立循环；没有替换成静态图片 |
| 页面与菜单 | Next 客户端导航；原生模态菜单支持焦点和 Escape | 菜单跳转与语言路径、查询、锚点检查通过 |
